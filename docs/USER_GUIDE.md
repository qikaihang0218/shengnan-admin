# 胜楠管理平台 · 用户操作手册

> 面向系统管理员与日常使用者。阅读前请确保已完成部署（见 `docs/DEVELOPER_GUIDE.md`）。
> 默认账号：`admin` / `admin123`（首次登录后请立即修改密码）。

---

## 1. 登录

1. 浏览器打开前端地址（本地开发默认 `http://localhost:5174`）。
2. 输入账号、密码、图形验证码。验证码点击图片可刷新。
3. 登录成功后进入「工作台」，左侧菜单由你的角色权限动态生成——**看不到某个菜单，说明你的角色没有对应权限**。登录状态由浏览器 Cookie 自动保持，刷新页面无需重新登录。
4. 右上角头像可退出登录。退出后会话 Cookie 被清除，令牌立即失效（黑名单机制）。登录凭据以 `HttpOnly` Cookie 保存，页面脚本无法读取，降低被盗风险。

## 2. 工作台

首页展示账号数、角色数、权限资源数、文件数四个概览卡片、当前账号的数据范围说明，以及「通知公告」栏（展示最新 5 条已发布通知）。

顶部导航栏右侧有**通知铃铛**（带未读数量角标），点击可查看全部通知并标记已读。

## 3. 系统管理

### 3.1 账号管理
- **查询**：输入账号/名称关键字后点「查询」。
- **新增账号**：填账号、名称、初始密码（留空默认 `123456`），选择角色和部门。
- **编辑**：可改名称、邮箱、手机、部门、角色、启停状态。**登录账号不可修改**。
- **重置密码**：输入新密码。
- **删除**：逻辑删除，账号不再可登录。
- 列表受**数据权限**影响：超级管理员看全部；普通角色按 `all/dept/dept_tree/self` 过滤。

### 3.2 角色管理
- 新增/编辑角色：设置名称、编码、数据范围、排序、说明。
  - **数据范围**：全部数据 / 本部门 / 本部门及以下 / 仅本人。
- **分配权限**：弹窗中勾选权限树（目录/菜单/动作），保存后该角色下的账号重新登录即生效。
- 超级管理员角色不可删除、不可停用。

### 3.3 权限资源
- 以树形展示「目录 / 菜单 / 动作」三级资源。
- 新增资源时选择父级、类型、路由、组件、图标、权限标识（如 `account:create`）。
- **删除父级前须先删除其子资源**。
- 该页面配置直接决定左侧菜单和按钮级权限。

### 3.4 部门管理 / 岗位管理
- 标准增删改查。部门支持树形层级；岗位用于账号归类。

### 3.5 字典管理
- 左栏是字典类型（如"性别"），右栏是选中类型下的字典项（文本/值/排序）。
- 先选中左侧类型才能维护右侧字典项。

### 3.6 系统参数
- 键值对形式的系统配置。`内置` 参数为系统运行必需，请勿随意修改。

### 3.7 通知公告（全员通知）
- 面向**所有登录账号**发布通知/公告，非管理员账号也能查看。
- **发布通知**：填标题、内容，选择类型（通知/公告）、是否置顶，可「直接发布」或存为「草稿」。
- **发布/撤回**：草稿点「发布」后所有账号可见；已发布点「撤回」后不再展示。
- **置顶**：置顶通知在列表和铃铛中排在最前。
- **全员查看入口**：顶部铃铛（未读角标）+ 工作台「通知公告」栏；点开通知自动标记已读，也可「全部标为已读」。
- 分配了 `notice:create/update/delete/publish` 权限的账号才能管理通知；仅 `notice:list` 或普通账号只能查看。
- **内容支持 Markdown**：编辑框上方有语法提示，可切到「预览」实时查看效果。支持标题（`#`）、粗体（`**文字**`）、斜体（`*文字*`）、列表（`-` / `1.`）、引用（`>`）、行内代码（`` `代码` ``）、代码块（三个反引号）、链接（`[文字](https://...)`）。
- **安全说明**：系统会过滤所有 HTML 与脚本，直接粘贴的 `<script>`、`onerror` 等只会作为文字显示；链接仅允许 http/https/mailto，`javascript:` 等危险协议会被剥离。因此请勿在内容中粘贴原始 HTML 源码。

## 4. 系统监控

### 4.1 登录记录
- 查看每次登录的账号、IP、系统、成功/失败状态、时间。
- 可清空全部记录。

### 4.2 操作日志
- 记录模块操作、请求地址、耗时、操作人、结果。可清空。

### 4.3 定时任务
支持三种任务类型：

| 类型 | 说明 | 权限要求 |
|---|---|---|
| Java 方法 | 调用内置方法，下拉选择（如 `systemTasks.heartbeat()`） | `job:create` |
| Shell 脚本 | 在服务器执行 shell/cmd 命令 | `job:script` |
| Java 代码 | 在线写 Java 代码，运行时编译执行 | `job:script` |

- **Cron 表达式**：6 位 `秒 分 时 日 月 周`，如 `0 0 2 * * ?` 表示每天凌晨 2 点。
- **状态开关**：打开=按 Cron 自动调度，关闭=暂停。
- **执行**：手动触发一次，结果即时弹出。
- **执行日志**：查看每次执行的类型、状态、耗时、输出信息。
- Shell/Java 代码任务属于高危能力，只有被授予 `job:script` 权限的角色才能配置和执行。

### 4.4 文件管理
- **上传**：支持多文件。
- **预览**：图片类文件直接在线预览。
- **下载**：下载原始文件。
- **删除**：同时删除逻辑记录和物理文件。

## 5. 权限与数据范围速查

- **功能权限**：由角色的权限标识（permission）控制，前端隐藏无权限的菜单/按钮，后端二次校验。
- **数据权限**：由角色的 `data_scope` 控制账号列表的可见范围。

| 数据范围 | 可见数据 |
|---|---|
| 全部数据 all | 所有账号 |
| 本部门 dept | 同部门账号 |
| 本部门及以下 dept_tree | 本部门及所有子部门账号 |
| 仅本人 self | 仅自己 |

### 主题切换
顶部导航栏右侧点击「主题」（画笔图标），可在 **深海蓝 / 森林绿 / 典雅紫 / 暖阳橙 / 暗夜黑** 五种主题间切换。选择会自动保存到浏览器本地，刷新后保持；主色会应用到按钮、菜单、标签等所有组件，暗夜黑为深色模式。

## 6. 常见问题

**Q：登录后菜单是空的？**
A：当前角色未分配任何菜单权限。用超管登录，在「角色管理 → 分配权限」中勾选菜单。

**Q：改了权限没生效？**
A：权限在登录时加载，需**重新登录**（或刷新页面触发用户信息重载）。

**Q：定时任务不执行？**
A：检查：① 任务是否启用；② Cron 表达式是否正确（6 位）；③ 查看执行日志中的错误信息。

**Q：无法上传文件？**
A：检查服务端 `platform.upload.dir` 目录是否有写权限；单文件默认上限 50MB。
